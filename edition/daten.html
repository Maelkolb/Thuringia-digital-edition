Je SeitePer page

Zu jeder Seite gibt es TEI-XML, JSON (das kanonische Datenformat der Edition mit Blöcken, Tabellen, Annotationen und Korrekturprotokoll) und reinen Text. Die Links stehen in der Leseansicht unter „Export“, etwaEvery page is available as TEI XML, JSON (the edition’s canonical data format with blocks, tables, annotations and correction log) and plain text. The links are in the reading view under “Export”, for example daten/seiten/54.xml, 54.json, 54.txt. Jede Tabelle des Buches ist zusätzlich als CSV abrufbar (Link unter der Tabelle).Every table of the book is also available as CSV (link below the table).

AuswertungenAnalyses

Jede Auswertung steht als JSON (Daten, Diagrammspezifikation, Texte) und ihre Datensätze als CSV zur Verfügung (Links auf der jeweiligen Seite). Das Format ist im JSON-Schema der Edition beschrieben.Each analysis is available as JSON (data, chart specification, texts), its datasets as CSV (links on each analysis page). The format is described by the edition’s JSON schema.
